# §21 Frontier — 최신 ANC 연구 (2020~2026)

학술 frontier 정리. 본 프로젝트 직접 적용 가능성 평가. 모든 결정은 §22 Grand Matrix로 통합.

---

## 21.1 Deep ANC (end-to-end NN)

**Zhang & Wang (2021, Neural Networks)** — "Deep ANC: A Deep Learning Approach to Active Noise Control"
- CRN (Convolutional Recurrent Network), STFT 도메인
- 비선형/비정상 noise에 SOTA
- 약 1~5M param, GPU 학습, CPU 추론 가능하나 임베디드는 어려움

**Shi et al. (2023)** — "Selective Fixed-Filter ANC based on convolutional neural network"
- pre-trained controller bank + CNN selector
- 학습된 환경에 대해 매우 robust
- Pi5 추론 가능 영역 (수십 ms latency)

**한계 (본 프로젝트)**:
- 사용자 데이터 ≥ 수 시간 필요
- C/NEON 추론 인프라 없음
- period=32 (0.33ms) budget 부적합

**판정**: ★ (Phase 5+, ML 인프라 구축 후).

---

## 21.2 Hybrid FxLMS + DNN

**Lu et al. (2022)** — DNN 기반 step-size scheduler
**Park et al. (2019)** — RNN reference predictor

**원리**: DNN이 mu, leak, 또는 reference 예측을 보조. inference rate 낮음(10~100ms).

**판정**: ★★ (Phase 4, §12 §12.2 동일).

---

## 21.3 Generative ANC / Diffusion models

**최근 (2024+)**: diffusion model로 anti-noise 직접 생성.
- inference cost 매우 큼 (수 초)
- 실시간 ANC 부적합

**판정**: ❌ (RT 부적합).

---

## 21.4 Federated / Transfer Learning ANC

**Federated**: 여러 사용자 데이터로 글로벌 모델 학습, 개인화는 local.
**Transfer**: 사전 학습된 model을 새 사용자에 fine-tune.

**적용**: 본 프로젝트 단일 사용자 시 transfer 적용 시 dataset 부족 보완.

**판정**: ★ (장기 비전, ML 인프라 전제).

---

## 21.5 Multi-channel Deep ANC

**Lou et al. (2024)** — MIMO Deep ANC
**Shi et al. (2024)** — multi-region selective NN

**필요**: 다채널 HW + GPU 학습.

**판정**: ★ (Phase 5+).

---

## 21.6 Online learning under non-stationary

**최근 (2023~)**: meta-learning 기반 빠른 적응 (MAML 등).

**ANC 응용**: 자세 변화 / sec_path drift 빠른 추적.

**판정**: ★ (학술 영역).

---

## 21.7 Neuromorphic / Spiking Neural Network ANC

**Loihi/Akida 같은 neuromorphic chip**: 매우 저전력 ANC 가능.
**임베디드 Pi5**: SNN 시뮬레이션은 가능하나 효율 ↓.

**판정**: ❌ (HW 별도 필요).

---

## 21.8 Quantum / 양자 알고리즘

**언급만**: 양자 컴퓨터 ANC는 학술 단계, 임베디드와 무관.

**판정**: ❌.

---

## 21.9 ANC + Speech Enhancement 통합

**최근 (2024~)**: ANC 출력에 speech enhancement 결합 (Wang et al., 2024).

**본 프로젝트**: 음성 통신 아님 → 부적합.

**판정**: ❌.

---

## 21.10 PSO / GA / Heuristic optimizer for ANC parameters

**원리**: Particle Swarm 또는 Genetic Algorithm으로 mu/leak/n_harm/BUF_LEN 최적화.

**용도**: 오프라인 하이퍼파라미터 튜닝.

**판정**: ★★ (오프라인 도구, Phase 2~3 보조). Python notebook으로 sim_compare.c 위에 wrapper 가능.

---

## 21.11 GAN 기반 sec_path identification

**최근 (2023)**: GAN으로 secondary path 비선형 모델 학습.

**효과**: 스피커 클리핑/IM 왜곡까지 포함된 sec_path → NLMS 발산 마진 ↑.

**판정**: ★ (본 시스템 OUTPUT_LIMIT 보호 충분).

---

## 21.12 Causal vs anti-causal trade-off 연구

**최근 (2022)**: causal sec_path 미스매치 대비 receding-horizon 보정.

**본 프로젝트 ref_lead=0**: 직접 도움 안 됨 (인과성 불가능).

**판정**: ★ (학술).

---

## 21.13 Selective ANC / Active Selective Noise Cancellation (SANC)

**원리**: 청취 중인 음성 통과 + 잡음만 캔슬. ML 분류기로 음성/잡음 구분.

**판정**: 본 프로젝트 청취 음성 없음 → 부적합. ❌

---

## 21.14 Pulse / impulsive ANC

**Akhtar (2020)** — α-stable noise 환경의 robust LMS

**원리**: heavy-tailed noise (impulse + 정상) 처리. 본 시스템 burst onset과 유사.

**판정**: ★★ (§13.5 Huber-LMS의 일반화).

---

## 21.15 Brain-controlled / EEG-feedback ANC

**최근**: 사용자 뇌파로 ANC 강도 조절.

**판정**: ❌ (의료기기 영역).

---

## 21.16 Listening tests / subjective evaluation

**최근 (2024)**: ANC 결과를 MUSHRA / MOS 형식 청취 평가.

**본 프로젝트**: 사용자 본인 청취 후 binary 판단 (효과 있다/없다).

**판정**: ★★★ (Phase 1+, 실측 메트릭 외 청취 검증 필수).

## 21.19 본 프로젝트 위치

**현재 (2026-05)**: 
- narrowband FxLMS + autocorr pitch tracking + per-harmonic mu_scale
- 학술 기준 standard, 임베디드 RT C 구현으로 견고
- frontier (Deep ANC) 대비 단순하나 검증 가능, 안전

**다음 5년 비전**:
1. Phase 0~2 표준 수립 (KB 게이트 통과 알고리즘)
2. Phase 3~4 (MIMO + 헤드레스트)
3. Phase 5+ (Tiny DNN hybrid, transfer learning)

**우선 방향**: frontier 기법보다 **§19 측정 신뢰 + §20 기하 + §07 인과성 우회** 먼저. 알고리즘 frontier는 본 시스템 천장 도달 후.
